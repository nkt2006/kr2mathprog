# Контрольная работа № 2 — kr2mathprog

Решения по файлу «Практические занятия Листок 2.pdf» (П. Е. Рябов): комплексные числа и их геометрия.

## Что открывать

- `Контрольная_работа_2_решения.pdf` — оформленные математические решения и графики.
- `Контрольная_работа_2.ipynb` — Jupyter Notebook с решениями, работающими программами, сохранёнными выводами и графиками. Дополнительные файлы для просмотра результатов не нужны.
- `figures/` — отдельные изображения всех построений.

Выполнены пункты 2.1–2.10, включая задания со звёздочкой. Оба задания с номером 2.10 из оригинала включены.

## Запуск

Нужен Python 3.10 или новее. Установите зависимости:

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyterlab
```

Откройте ноутбук и выберите **Run → Run All Cells**. Все изображения будут заново сохранены в `figures/`. Код проверен последовательным выполнением всех ячеек.

## Особенности исходного условия

1. В 2.4e нижняя граница аргумента −2π/3 больше верхней −5π/6. При буквальном прочтении ответ — пустое множество. Границы самовольно не переставлялись.
2. В 2.7c строится Arg(C_z^(1/z)): показатель в оригинале — именно 1/z.
3. В задачах о сфере Римана конкретные коэффициенты кривых и спирали не заданы. В решении явно указаны выбранные параметры; их можно менять в ноутбуке.
4. Листок посвящён комплексным числам. Ранее на странице КР-2 СДО были указаны дифференциальные уравнения. Выполнена работа именно по присланному листку; принадлежность листка к КР-2 определяется указаниями преподавателя.
